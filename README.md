# Sales-Reconciliation-Automation-Using-App-Script-
Developed   an automated data reconciliation process to consolidate and validate   transaction records per period from multiple marketplace channels, settlement   reports, and internal data sources. Improved data processing efficiency by   approximately 67%, reducing reconciliation time from over 5 hours to less   than 2 hour.

## 📌 Project Overview

This project is designed to automate the sales reconciliation preparation process using **Google Apps Script (JavaScript)** and Google Sheets.

The automation streamlines the process of collecting sales transaction data and consolidating Purchase Order (PO) records from multiple sources into a centralized dataset.

By reducing repetitive manual data collection and spreadsheet operations, this solution helps improve data processing efficiency, consistency, and readiness for the reconciliation process.

## 🎯 Project Objectives

- Automate sales transaction data collection from multiple Google Sheets sources.
- Consolidate Purchase Order (PO) data into a centralized dataset.
- Reduce repetitive manual data processing.
- Improve data consistency and minimize manual handling errors.
- Prepare structured datasets for further sales reconciliation and validation.

## ⚙️ Automation Workflow

The project consists of two main automation modules:

### 1. Sales Data Collection

Collects sales transaction data from multiple source sheets and consolidates the records into a centralized dataset.

**Key processes:**
- Retrieve transaction data from multiple source sheets.
- Standardize and consolidate collected records.
- Append data into the designated master dataset.
- Reduce manual copy-paste operations.

### 2. Purchase Order (PO) Collection

Automates the collection and consolidation of Purchase Order data from multiple sources.

**Key processes:**
- Retrieve PO records from designated source sheets.
- Collect relevant PO information.
- Consolidate records into a centralized dataset.
- Prepare PO data for further matching and reconciliation.
